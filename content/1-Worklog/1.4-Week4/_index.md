### Weekly Theme

Explore Amazon S3 unstructured storage, configure permissions, and host static web applications.

### Weekly Objectives

* Manage Amazon S3 Buckets and protect data using Versioning.
* Understand how to write Bucket Policies to grant access rights.
* Set up Static Website Hosting.

### Task Schedule

| Date | Day | Task Description | Lab / Project |
|---|---|---|---|
| 11/05/2026 | Monday | Create an S3 Bucket, perform file Upload/Download. Enable S3 Versioning and test file recovery from overwrites. | [Lab 000010 - Amazon S3 Administration](https://000010.awsstudygroup.com) |
| 12/05/2026 | Tuesday | Learn IAM Policy for S3. Use Block Public Access to prevent unintentional data leakage. | [Lab 000010 - Amazon S3 Administration](https://000010.awsstudygroup.com) |
| 13/05/2026 | Wednesday | Enable Static Website Hosting. Write a policy granting Public Read access to directly host a front-end interface. | [Lab 000011 - S3 Static Web Hosting](https://000011.awsstudygroup.com) |

### Expected Outcomes

* Successfully host a static HTML website without running an EC2 instance, helping to maximize cost savings.
* Protect the data repository through the versioning mechanism.
